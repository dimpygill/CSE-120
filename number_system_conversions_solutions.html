Number System Conversions — Detailed Solutions

Six worked examples showing each conversion step. Total: 6 points.

1. Binary → Decimal: 1011101₂

Assign powers of 2 from right to left:

Binary digit1011101
Power2⁶2⁵2⁴2³2²2¹2⁰
Value640168401

Add: 64 + 0 + 16 + 8 + 4 + 0 + 1 = 93.

Answer: 1011101₂ = 93₁₀

2. Decimal → Binary: 53₁₀

Divide repeatedly by 2 and record each remainder.

Read remainders from bottom to top: 110101.

Answer: 53₁₀ = 110101₂

3. Binary → Hexadecimal: 11010110₂

Group digits into sets of four from the right: 1101 0110.

Binary groupDecimal valueHex digit
11018 + 4 + 0 + 1 = 13D
01100 + 4 + 2 + 0 = 66

Combine the digits: D6.

Answer: 11010110₂ = D6₁₆

4. Hexadecimal → Binary: B7₁₆

Replace each hexadecimal digit with its four-bit binary equivalent.

Hex digitDecimal4-bit binary
B111011
770111

Combine: 1011 0111.

Answer: B7₁₆ = 10110111₂

5. Decimal → Hexadecimal: 189₁₀

Divide by 16: 189 ÷ 16 = 11 remainder 13.

Convert the quotient and remainder to hexadecimal: 11 = B and 13 = D. Write them in order: BD.

Check: (11 × 16) + 13 = 176 + 13 = 189.

Answer: 189₁₀ = BD₁₆

6. Hexadecimal → Binary: 4E₁₆

Convert each hexadecimal digit to four binary bits.

Hex digitDecimal4-bit binary
440100
E141110

Combine: 0100 1110. The leading zero can be omitted, giving 1001110.

Answer: 4E₁₆ = 01001110₂ (also 1001110₂)
