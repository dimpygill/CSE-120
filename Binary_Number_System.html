Binary Number System

Introduction to why computers use binary, how positional number systems work, and how to convert between decimal and binary, with interactive practice.

1. Why Do We Need to Learn the Binary Number System?

We use computers to write documents, perform calculations, watch videos, and run applications. But how does a computer represent numbers, letters, images, and instructions?

Start with a familiar number: 5

When we type 5, we recognize it as a decimal number. Inside a computer, information is represented using electronic circuits that can reliably distinguish two logical states, commonly described as LOW (0) and HIGH (1). The states are represented by binary digits; they are not necessarily literal off/on switches.

0LOWOne logical state
1HIGHAnother logical state

Because there are two logical states, a two-digit system is a natural way to represent information in digital circuits. This is the binary number system.

The same value, two representations:
Decimal (Base 10)5
→
Binary (Base 2)101

Both represent the same numerical quantity. Later, we will learn why decimal 5 is written as binary 101.

Why is binary important in computer science?

  • Numbers: Numeric values can be encoded in binary.
  • Text: Characters are mapped to numeric codes and stored as bits.
  • Images: Pixel information is encoded as numbers stored in binary.
  • Programs: Machine instructions are represented as bit patterns.
  • Memory: Physical storage states represent binary information.

Where are we going next?

We will first examine the familiar decimal number system and its powers of 10. Then we will use the same place-value idea with powers of 2, before learning to convert between decimal and binary.

Learning goal: Understand not only how to convert numbers, but why binary is used in computers and how binary represents values.

2. Introduction to Number Systems

A number system represents quantities using digits and positional rules. The base (or radix) tells us how many distinct digits the system uses.

SystemBaseDigitsExample representing decimal 25
Decimal100–925
Binary20, 111001
Octal80–731
Hexadecimal160–9, A–F19

Decimal is familiar in everyday life. Computers use binary to represent information because electronic circuits can reliably distinguish two logical states.

3. What Is Binary?

Binary uses just 0 and 1. Each digit is called a bit. Four bits make a nibble; eight bits make a byte. A binary digit represents one of two possible logical states, often associated with low and high voltage levels in electronic circuits.

Example: 10110101 has 8 bits, so it can be represented in one byte.

4. Understanding Binary Place Values

First, understand decimal place values (powers of 10)

The decimal number system has base 10 because it uses ten digits (0 through 9). Each digit has a place value determined by its position. Starting at the rightmost digit, the positions are ones, tens, hundreds, thousands, and so on.

Each position is a power of 10. The exponent tells us how many factors of 10 are multiplied together. By definition, 10⁰ = 1.

PositionThousandsHundredsTensOnes
Power10³10²10¹10⁰
Place value1000100101
Worked example: What does 325 mean?

In 325, the digit 3 is in the hundreds place, 2 is in the tens place, and 5 is in the ones place.

DigitPositionCalculationContribution
3Hundreds (10²)3 × 100300
2Tens (10¹)2 × 1020
5Ones (10⁰)5 × 15

325 = (3 × 100) + (2 × 10) + (5 × 1) = 300 + 20 + 5.

Why powers of 10? Each time we move one place to the left, the place value becomes 10 times larger: 1 → 10 → 100 → 1000. For example, 10² = 10 × 10 = 100, and 10³ = 10 × 10 × 10 = 1000.

Comparing decimal and binary place values

Binary follows the same positional rule, but its base is 2, so moving one place to the left multiplies the place value by 2, not 10.

Position from right (starting at 0)Decimal: powers of 10Binary: powers of 2
010⁰ = 12⁰ = 1
110¹ = 102¹ = 2
210² = 1002² = 4
310³ = 10002³ = 8
410⁴ = 100002⁴ = 16

Key idea: In a positional number system, the place values are powers of the base. Decimal uses powers of 10; binary uses powers of 2.

In decimal, the place values are powers of 10: 1, 10, 100, 1000, and so on. In binary, they are powers of 2: 1, 2, 4, 8, 16, 32, 64, 128, and so on.

5. Binary to Decimal Conversion

Method: Starting at the rightmost digit, assign powers of 2 (beginning at 2⁰). Multiply each digit by its place value and add the products.

Worked example: (110101)₂

Binary digit110101
Place value32168421
Contribution32160401

Answer: 32 + 16 + 0 + 4 + 0 + 1 = 53.

6. Decimal to Binary Conversion

Repeated division by 2: Divide the number by 2, record the remainder, then divide the quotient again. Continue until the quotient is zero. Read the remainders from bottom to top.

Worked example: Convert 25 to binary

DivisionQuotientRemainder
25 ÷ 2121
12 ÷ 260
6 ÷ 230
3 ÷ 211
1 ÷ 201

Reading upward: (25)₁₀ = (11001)₂.

8. Summary

  • Binary is a positional Base-2 number system using only 0 and 1.
  • Decimal place values are powers of 10; binary place values are powers of 2.
  • Convert binary to decimal by multiplying each bit by its place value and adding the results.
  • Convert decimal to binary using repeated division by 2 and reading remainders from bottom to top.
  • Each position to the left doubles in binary and increases tenfold in decimal.
