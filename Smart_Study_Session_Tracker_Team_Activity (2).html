Team Challenge: Smart Study Session Tracker

35 Minutes2 Students per Team10 PointsPython Programming

Learning Objectives

Work with a partner to design, develop, and test a Python program while practicing active listening, clear communication, constructive feedback, shared decision-making, and accountability. Both partners must understand the final program and contribute to its development.

Part 1 — The Programming Challenge

Scenario: Your college wants a simple tool to help students monitor their study habits. Your two-person team has been asked to build a Smart Study Session Tracker.

Program Requirements

  1. Ask the user to enter the number of hours spent studying during a session.
  2. Allow the user to enter multiple study sessions.
  3. If the user enters 0, display Session skipped. Do not count it toward the total or number of valid sessions.
  4. If the user enters -1, stop collecting sessions and display the final report.
  5. For each valid session, display its category using the table below.
  6. Track the total study hours and number of valid sessions.
  7. Calculate the average hours per valid session.
  8. Display a readable final summary. If no valid sessions were recorded, display an appropriate message without attempting to calculate an average.
  9. If the user enters a negative number other than -1, display an error message and allow another entry.
Study hoursCategory
Greater than 0 and less than 1Short Session
1 to less than 3Moderate Session
3 or moreLong Session
Design challenge: Your team decides how to implement these requirements using Python concepts you have learned. Discuss your approach and agree on a plan before coding. You are not given a prescribed implementation.

Example Program Interaction

SMART STUDY SESSION TRACKER Enter study hours: 2 Moderate Session Enter study hours: 0 Session skipped. Enter study hours: 3.5 Long Session Enter study hours: 0.5 Short Session Enter study hours: -1 ------ STUDY SUMMARY ------ Valid sessions: 3 Total study hours: 6.0 Average hours: 2.0 ---------------------------

Your output may look different, but it must satisfy the program requirements.

Teamwork Expectations

  • Both partners must contribute; one person should not complete the entire task alone.
  • Listen fully, ask questions, and confirm understanding before making changes.
  • When ideas differ, compare them against the requirements rather than criticizing the person.
  • Give specific, respectful feedback and accept corrections constructively.
  • Both partners must be able to explain the final program.

Part 4 — Individual Teamwork Reflection

Each partner answers the following in 1–2 sentences per question:

  1. Contribution: What did you personally contribute to the program?
  2. Collaboration: How did your partner help improve the program or your understanding?
  3. Communication: Describe one question, suggestion, or disagreement you discussed. How did you reach a decision?
  4. Team development: Which stage best describes your team today—Forming, Storming, Norming, or Performing? Give a specific observed behavior.
  5. Next step: What is one action that would improve your next team meeting?
