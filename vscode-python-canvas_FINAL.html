Setup Guide

Run Python in VS Code.

A step-by-step walkthrough — from a fresh machine to running your first Python file. Instructions are provided for all three operating systems.

🪟 Windows 🍎 macOS 🐧 Linux ● 7 steps  ·  ~15 minutes
Follow your OS: WIN Windows MAC macOS LINUX Linux (Ubuntu/Debian)
1

Install Python

Go to the official Python website and download Python for your operating system:

python.org/downloads
WIN

Click the yellow Download Python button to get the Windows installer (.exe). Run it.

⚠ Critical: On the very first screen, check "Add Python to PATH" before clicking Install Now. Do not skip this.

MAC

Click Download Python to get the macOS installer (.pkg). Open it and follow the prompts — click Continue, Agree, and Install. No extra checkboxes needed.

After installing, open Terminal (search for it in Spotlight with ⌘+Space) and verify it worked:

Terminal
$ python3 --version
Python 3.12.4
Note for Mac: Always use python3 instead of python on macOS.
LINUX

Python is likely already installed. Open a Terminal and check:

$ python3 --version
Python 3.12.x

If you see a version number, you're done. If not, install it with:

$ sudo apt update
$ sudo apt install python3
2

Install VS Code

Download VS Code from Microsoft's official site:

code.visualstudio.com
WIN

Click Download for Windows. Run the .exe installer and keep clicking Next through all the default settings, then click Install.

Tip: When the installer finishes, keep "Launch Visual Studio Code" checked and click Finish — VS Code opens automatically.
MAC

Click Download for macOS. Open the downloaded .zip — it will extract Visual Studio Code.app. Drag that file into your Applications folder, then open it from there.

Tip: Right-click the VS Code icon in your dock and choose Options → Keep in Dock for easy access.
LINUX

Download the .deb package (for Ubuntu/Debian). Then install it by running:

$ sudo dpkg -i code_*.deb

Then launch VS Code by typing code in the terminal, or find it in your application menu.

3

Install the Python extension

This step is identical on all operating systems. Open VS Code, then on the left sidebar click the Extensions icon (four squares). Search for Python and install the one published by Microsoft (120M+ installs).

4

Open your project folder

First create a folder for your work, then open it in VS Code. The process is the same on all systems — only where you create the folder differs.

WIN

Create a folder on your Desktop named my-python-project.

MAC

Create a folder in your Documents named my-python-project.

LINUX

Create a folder in your home directory named my-python-project, or run:

$ mkdir ~/my-python-project
Then on all systems: In VS Code go to File → Open Folder, navigate to your new folder, and click Select Folder.
5

Create a .py file

Same on all systems. In the Explorer panel on the left, click the New File icon and name it hello.py. Then type this code:

hello.py
# hello.py
print("Hello, world!")
name = "Ada"
print("Hello, " + name + "!")
for i in range(3):
print("Count: " + str(i))

Save the file before running — VS Code shows a dot (●) on the tab if there are unsaved changes.

WIN Save: Ctrl+S
MAC Save: ⌘+S
LINUX Save: Ctrl+S
6

Select your Python interpreter

VS Code needs to know which Python to use. Open the Command Palette, then type and select Python: Select Interpreter.

WIN Ctrl+Shift+P
MAC ⌘+Shift+P
LINUX Ctrl+Shift+P
Select Interpreter
Enter interpreter path or pick one below
★ Python 3.12.x  ← select this
Tip: You only need to do this once per folder. VS Code will remember your choice.
7

Run the file

Make sure hello.py is open and saved, then click the ▶ Play button in the top-right corner of VS Code. This works the same on all systems.

hello.py
print("Hello, world!")
name = "Ada"
print("Hello, " + name + "!")
Terminal
$ python hello.py
Hello, world!
Hello, Ada!
Count: 0
Count: 1
Count: 2
🎉 You did it! If you see the output in the Terminal panel at the bottom of VS Code, Python is working perfectly.
Mac/Linux note: If the play button uses python3 instead of python in the terminal output — that's completely normal and correct.

Common errors & fixes

'python' is not recognized as an internal or external command
WIN Fix: Re-run the Python installer and check "Add Python to PATH" on the first screen.
command not found: python
MAC LINUX Fix: Use python3 instead of python. On Mac and Linux, Python 3 is always called python3.
SyntaxError: invalid syntax
All systems. Cause: A typo in your code — missing colon, mismatched bracket, or misspelled keyword. Fix: Look for the red underline in VS Code and check your spelling and punctuation on that line.
Changes to my file aren't showing when I run it
All systems. Fix: Save first. Windows/Linux: Ctrl+S  ·  Mac: ⌘+S. A dot (●) on the tab means unsaved changes.
The ▶ Play button isn't showing up
All systems. Fix: The play button only appears for .py files when the Python extension is installed. Go back to Step 3 and install the Microsoft Python extension.
