Student Score Analyzer

Practice input, variables, conditions, while, break, continue, and string concatenation — without lists or arrays.

Part 1

Programming Problem

Write a Python program called Student Score Analyzer. The program asks the user to enter student scores, accepts up to five valid scores, and reports how many scores are passing or failing.

Requirements

  1. Prompt for a score repeatedly using a while loop, stopping after five valid scores.
  2. Accept whole-number scores from 0 to 100 inclusive. Assume the user enters integers; handling nonnumeric input is not required.
  3. If the user enters -1, immediately stop accepting scores using break. Do not count -1 as a score.
  4. If the score is below 0 or above 100 (other than -1), print an error message and use continue to request another score. Invalid scores do not count toward the five.
  5. Count valid scores and calculate a running total.
  6. Build a comma-separated display of the valid scores by adding each value to a string variable during the loop. Do not use lists or arrays.
  7. Count a score of 60 or higher as a pass; a score below 60 is a failure.
  8. After input ends, display the valid scores, total number of valid scores, number of passes, and number of failures. If there are no valid scores, display None.
  9. Include comments explaining the purpose of the major steps.
Explore multiple scenarios: Try normal scores, boundary values (0, 60, 100), invalid scores (-5, 120), stopping immediately with -1, stopping after some valid scores, and entering five valid scores.
Example

Sample Input and Expected Output

This is only one example. Your program should work for other valid and invalid input sequences too.

Enter a score (or -1 to stop): 85
Enter a score (or -1 to stop): 45

Part 2

Reference Solution (With Comments)

This is one correct approach. It processes each score as soon as it is entered, without storing scores in a list.

# Student Score Analyzer: Reference Solution

total = 0
valid_count = 0
passes = 0
failures = 0
score_list = ""  # Store scores as text for display.

# Continue until five valid scores are entered.
while valid_count < 5:

    score = int(input("Enter a score (or -1 to stop): "))

    # Stop when the user enters -1.
    if score == -1:
        break

    # Reject scores outside the valid range.
    if score < 0 or score > 100:
        print("Invalid score. Enter a score from 0 to 100.")
        continue  # Skip this score and repeat the loop.

    # Count the valid score.
    valid_count += 1

    # Add the score to the running total.
    total += score

    # Add the score to the text for display.
    if score_list == "":
        score_list = str(score)
    else:
        score_list += ", " + str(score)

    # Check whether the score is passing or failing.
    if score >= 60:
        passes += 1
    else:
        failures += 1

# Display the final report.
print("\n--- Student Score Report ---")

if valid_count > 0:
    print("Valid scores:", score_list)
else:
    print("Valid scores: None")

print("Total valid scores:", valid_count)
print("Passes:", passes)
print("Failures:", failures)
