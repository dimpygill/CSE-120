Number Systems and Conversions

Beginner-friendly tutorial | Binary, Decimal, Octal, and Hexadecimal | Python fundamentals

1. Types of Number Systems

SystemBaseAllowed digitsExampleTypical use
Decimal100–925₁₀Everyday numbers
Binary20, 111001₂Representing bits in computers
Octal80–731₈Compact 3-bit groups; Unix permissions
Hexadecimal160–9, A–F19₁₆Memory addresses, bytes, colors

All four examples above represent the same value: decimal 25. The base determines the place values. Decimal uses powers of 10, binary powers of 2, octal powers of 8, and hexadecimal powers of 16.

Why learn this? Computers store bits, but people need readable ways to write, inspect, and interpret the same values. Hexadecimal and octal are not extra storage formats: they are number notations.

4. Binary → Decimal (Powers of 2)

Starting at the rightmost bit, multiply each digit by 2 raised to its position (0, 1, 2, …), then add.

1101₂ = 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 8 + 4 + 0 + 1 = 13₁₀.

5. Binary ↔ Hexadecimal (4 Bits per Hex Digit)

Because 16 = 2⁴, one hexadecimal digit equals exactly four binary bits.

Binary → Hex: Steps

Group bits into fours from right to left. Add leading zeros to the leftmost group if needed. Replace each group using the table.

11111111₂ → 1111 | 1111 → FF₁₆
101101₂ → 0010 | 1101 → 2D₁₆
1101₂ → 1101 → D₁₆
10011010₂ → 1001 | 1010 → 9A₁₆

Hex → Binary: Steps

Replace each hex digit with four bits; retain leading zeros within groups.

2F₁₆ → 0010 | 1111 → 00101111₂
A3₁₆ → 1010 | 0011 → 10100011₂
7C₁₆ → 0111 | 1100 → 01111100₂
FF₁₆ → 1111 | 1111 → 11111111₂

Leading zeros do not change the numeric value, but preserving four-bit groups makes hex conversions easier to read.

2F₁₆ = 2×16¹ + 15×16⁰ = 32 + 15 = 47
1A₁₆ = 1×16¹ + 10×16⁰ = 26
FF₁₆ = 15×16¹ + 15×16⁰ = 255
12C₁₆ = 1×16² + 2×16¹ + 12×16⁰ = 256 + 32 + 12 = 300

7. Octal and Binary (3 Bits per Octal Digit)

Because 8 = 2³, one octal digit represents three binary bits.

Binary → Octal: 110101₂ → 110 | 101 → 65₈
Binary → Octal: 10111₂ → 010 | 111 → 27₈
Octal → Binary: 34₈ → 011 | 100 → 011100₂
Octal → Binary: 72₈ → 111 | 010 → 111010₂

Practical example: Unix-style file permissions use octal digits such as 755; each digit encodes three permission bits.

8. Practical Application: Hexadecimal Colors

In CSS, a common color format is #RRGGBB. Each two-digit hex pair specifies an intensity from 00 (0) to FF (255).

ColorHex codeRGB decimal valuesPreview
Red#FF0000(255, 0, 0)
Green#00FF00(0, 255, 0)
Blue#0000FF(0, 0, 255)
Orange#FFA500(255, 165, 0)
Dark red#800000(128, 0, 0)
Light pink#FF8080(255, 128, 128)
Why hex instead of color names? Names such as "red" are convenient, but hex codes precisely describe many custom shades. Hex is a human-readable notation; the underlying channel values are still numeric.

9. Python: Number-System Prefixes

LiteralMeaningDecimal value
13Decimal13
0b1101Binary13
0o15Octal13
0xDHexadecimal13
n = 13
print(bin(n))          # 0b1101
print(oct(n))          # 0o15
print(hex(n))          # 0xd
print(int("1101", 2))  # 13
print(int("15", 8))    # 13
print(int("D", 16))    # 13
print(0b1101 == 0xD)  # True

Python knows the base from the prefix when parsing a numeric literal, or from the explicit base argument in int(). Numeric values do not need to remember which notation was used.

11. Key Takeaways

Decimal ↔ Binary: divide by 2 or use powers of 2.
Binary ↔ Hex: group four bits per hex digit.
Decimal ↔ Hex: divide by 16 or use powers of 16.
Binary ↔ Octal: group three bits per octal digit.
Python: use 0b, 0o, and 0x for numeric literals.
