CSE 120

Problem

Write a Python program for a college course registration system.

Program Requirements

  • Ask the student to enter their age.
  • Ask the student to enter their GPA.
  • Ask whether the student has completed the prerequisite course. The student should enter yes or no.
  • Convert the age to an appropriate numeric data type.
  • Convert the GPA to an appropriate numeric data type.
  • If the student's GPA is 3.0 or higher AND the prerequisite course has been completed, display:
    You are eligible for the Advanced Course.
  • Otherwise, if the student's GPA is 2.0 or higher AND the student is 18 or older, display:
    You are eligible for the Regular Course.
  • Otherwise, display:
    You are not currently eligible to register.
  • Your program must use input(), if, elif, else, the logical operator and, comparison operators, and print().

Solution

Below is one correct solution to the problem.

age = int(input("Enter your age: ")) gpa = float(input("Enter your GPA: ")) prerequisite = input("Have you completed the prerequisite course? yes/no: ") if gpa >= 3.0 and prerequisite == "yes": print("You are eligible for the Advanced Course.") elif gpa >= 2.0 and age >= 18: print("You are eligible for the Regular Course.") else: print("You are not currently eligible to register.")

Expected Results

The following examples demonstrate how the program behaves with different user input.

Example 1 — Advanced Course
User Input
Enter your age: 20
Enter your GPA: 3.5
Have you completed the prerequisite course? yes/no: yes
Output
You are eligible for the Advanced Course.
Why?
  • gpa >= 3.0 → True
  • prerequisite == "yes" → True
  • True and True → True
Therefore, the if branch executes.
Example 2 — Regular Course
User Input
Enter your age: 21
Enter your GPA: 2.6
Have you completed the prerequisite course? yes/no: no
Output
You are eligible for the Regular Course.
Why?

The Advanced Course condition is False, so Python moves to the elif.

  • gpa >= 2.0 → True
  • age >= 18 → True
  • True and True → True
Therefore, the elif branch executes.
Example 3 — Not Eligible
User Input
Enter your age: 17
Enter your GPA: 1.8
Have you completed the prerequisite course? yes/no: no
Output
You are not currently eligible to register.
Why?
  • The Advanced Course condition is False.
  • The Regular Course condition is False.
  • Python reaches the else branch.

Key Points

  • input() receives information from the user.
  • int() converts the age to an integer.
  • float() converts the GPA to a decimal number.
  • if checks the first condition.
  • elif checks another condition when the previous condition is False.
  • else handles the default scenario.
  • and means that both conditions must be True.
  • Python executes the first matching branch in an if / elif / else chain.
