Digital Logic: Six More Scenario Questions and Detailed Solutions

Gate symbols:AND: all inputs must be 1OR: at least one input must be 1NOT: reverses 0 and 1

Practice translating everyday requirements into inputs, complete truth tables, Boolean expressions, and logic gate circuits.

Notation: 0 = OFF/False, 1 = ON/True; · means AND, + means OR, ¬ means NOT. OR is inclusive. Every question uses three binary inputs, so each truth table has eight rows.

Question 4 — Automatic Garden Light

Scenario: A garden light turns ON when it is dark (A) AND motion is detected (B), provided the manual disable switch is OFF (C).
Tasks
  1. Identify the inputs A, B, C and output Y, defining 0 and 1.
  2. Write the condition in words.
  3. Construct the complete eight-row truth table.
  4. Write the Boolean expression.
  5. Draw the circuit and explain two test cases.

Solution 1: Inputs and output

Solution 2: Condition in words

Solution 4: Boolean expression

Y = A · B · ¬C

Solution 5: Gate-by-gate circuit construction

Gate 1 NOT C
Gate 2 AND A, B, ¬C

Connect the output of the final gate to Y. Intermediate gate outputs feed the next gate as described above.

Solution 6: Detailed reasoning

  1. Invert C using NOT.
  2. AND the values A, B and ¬C.
  3. Y is 1 only if all three values entering AND are 1.
Worked test case: Dark=1, motion=1, disable=0: ¬C=1 and Y=1. If motion is absent, the light stays off.

Review

Compare the expressions: AND requires all its inputs; OR requires at least one; NOT reverses a value. Parentheses show which gate result must be calculated first. Different real-world stories can have identical Boolean expressions.
