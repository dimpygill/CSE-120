12 questions: two detailed worked examples for each of six conversion types.

Reference Charts: Binary, Hexadecimal and Octal

Important: Binary uses only 0 and 1. For example, decimal 4 is binary 100, and octal 4 is written 4. Octal 7 = binary 111. Each hexadecimal digit corresponds to 4 bits; each octal digit corresponds to 3 bits.

Decimal → Binary

Question 1: Convert 25₁₀ to binary

Steps: 25 ÷ 2 = 12 remainder 1; 12 ÷ 2 = 6 remainder 0; 6 ÷ 2 = 3 remainder 0; 3 ÷ 2 = 1 remainder 1; 1 ÷ 2 = 0 remainder 1. Read remainders upward.

Answer: 11001₂

Question 2: Convert 42₁₀ to binary

Steps: 42 ÷ 2 = 21 r0; 21 ÷ 2 = 10 r1; 10 ÷ 2 = 5 r0; 5 ÷ 2 = 2 r1; 2 ÷ 2 = 1 r0; 1 ÷ 2 = 0 r1. Read upward.

Answer: 101010₂

Binary → Decimal

Question 1: Convert 101101₂ to decimal

Steps: 1×2⁵ + 0×2⁴ + 1×2³ + 1×2² + 0×2¹ + 1×2⁰ = 32 + 8 + 4 + 1.

Answer: 45₁₀

Question 2: Convert 110010₂ to decimal

Steps: 1×2⁵ + 1×2⁴ + 0×2³ + 0×2² + 1×2¹ + 0×2⁰ = 32 + 16 + 2.

Answer: 50₁₀

Binary → Hexadecimal

Question 1: Convert 11111100₂ to hexadecimal

Steps: Group from right: 1111 1100. 1111 = F; 1100 = C.

Answer: FC₁₆

Question 2: Convert 101101₂ to hexadecimal

Steps: Pad on left: 0010 1101. 0010 = 2; 1101 = D.

Answer: 2D₁₆

Hexadecimal → Binary

Question 1: Convert 3A₁₆ to binary

Steps: 3 = 0011; A = 1010. Join both four-bit groups.

Answer: 00111010₂

Question 2: Convert 40FF₁₆ to binary

Steps: 4 = 0100; 0 = 0000; F = 1111; F = 1111. Join groups.

Answer: 0100000011111111₂

Binary → Octal

Question 1: Convert 110101₂ to octal

Steps: Group from right in threes: 110 101. 110 = 6; 101 = 5.

Answer: 65₈

Question 2: Convert 1011110₂ to octal

Steps: Pad on left: 001 011 110. Groups give 1, 3, 6.

Answer: 136₈

Octal → Binary

Question 1: Convert 75₈ to binary

Steps: 7 = 111; 5 = 101. Join three-bit groups.

Answer: 111101₂

Question 2: Convert 246₈ to binary

Steps: 2 = 010; 4 = 100; 6 = 110. Join groups.

Answer: 010100110₂
