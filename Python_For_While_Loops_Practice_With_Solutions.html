Exercise 1 — Print Numbers 1 to 5

Use a for loop to print the numbers from 1 through 5, one number per line.

Expected output:

1
2
3
4
5

Solution:

for number in range(1, 6):
    print(number)

Exercise 2 — Print Numbers 1 to 5 with a While Loop

Use a while loop to print the numbers from 1 through 5.

Expected output:

1
2
3
4
5

Solution:

number = 1

while number <= 5:
    print(number)
    number = number + 1

Exercise 3 — Count from 5 Down to 1

Use a while loop to count backward from 5 to 1. After the loop, print Done!.

Expected output:

5
4
3
2
1
Done!

Solution:

number = 5

while number >= 1:
    print(number)
    number = number - 1

print("Done!")

Exercise 4 — Print Even Numbers

Use a for loop and an if statement to print only the even numbers from 1 through 10.

Expected output:

2
4
6
8
10

Solution:

Exercise 5 — Odd or Even

Use a for loop to check the numbers 1 through 5. Use if/else to display whether each number is odd or even.

Expected output:

1 is odd
2 is even
3 is odd
4 is even
5 is odd

Solution:

for number in range(1, 6):
    if number % 2 == 0:
        print(number, "is even")
    else:
        print(number, "is odd")

Exercise 6 — Multiplication Table

Ask the user to enter a number. Use a for loop to display its multiplication table from 1 through 5.

Example expected output if the user enters 3:

Enter a number: 3
3 x 1 = 3
3 x 2 = 6
3 x 3 = 9
3 x 4 = 12
3 x 5 = 15

Solution:

number = int(input("Enter a number: "))

for i in range(1, 6):
    print(number, "x", i, "=", number * i)

Exercise 7 — Add Numbers 1 Through 5

Use a for loop to add the numbers 1 through 5. Display the final total after the loop.

Expected output:

Total = 15

Solution:

total = 0

for number in range(1, 6):

Exercise 8 — Positive, Negative, or Zero

Ask the user to enter three numbers, one at a time. Use a while loop. For each number, use if/elif/else to print whether it is positive, negative, or zero.

Example expected output for inputs 8, -2, and 0:

Enter a number: 8
Positive
Enter a number: -2
Negative
Enter a number: 0
Zero

Solution:

count = 1

while count <= 3:
    number = int(input("Enter a number: "))

    if number > 0:
        print("Positive")
    elif number < 0:
        print("Negative")
    else:
        print("Zero")

    count = count + 1

Exercise 9 — Grade Categories

Ask the user to enter three grades, one at a time. Use a for loop and if/elif/else. Print A for 90 or higher, B for 80–89, C for 70–79, and Needs Improvement for a grade below 70.

Example expected output for grades 95, 84, and 62:

Enter grade: 95
A
Enter grade: 84
B
Enter grade: 62
Needs Improvement

Solution:

for i in range(3):

    if grade >= 90:
        print("A")
    elif grade >= 80:
        print("B")
    elif grade >= 70:
        print("C")
    else:
        print("Needs Improvement")

Exercise 11 — Keep Asking Until the Correct Number

Set a secret number equal to 7. Keep asking the user to guess until the user enters 7. If the guess is too low, print Too low. If it is too high, print Too high. When correct, print Correct!.

Example expected output:

Guess the number: 4
Too low
Guess the number: 9
Too high
Guess the number: 7
Correct!

Solution:

secret = 7
guess = 0

while guess != secret:
    guess = int(input("Guess the number: "))

    if guess < secret:
        print("Too low")
    elif guess > secret:
        print("Too high")
    else:
        print("Correct!")

Exercise 12 — Simple Menu

Create a simple menu that repeats until the user enters 3. Option 1 prints Hello!, option 2 prints Welcome to Python!, and option 3 prints Goodbye!. Use a while loop and if/elif/else.

Example expected output:

1. Say Hello
2. Welcome Message
3. Exit
Enter choice: 1
Hello!
1. Say Hello
2. Welcome Message
3. Exit
Enter choice: 3
Goodbye!

Solution:

choice = 0

while choice != 3:
    print("1. Say Hello")
    print("2. Welcome Message")
    print("3. Exit")
    choice = int(input("Enter choice: "))

    if choice == 1:
        print("Hello!")
    elif choice == 2:
        print("Welcome to Python!")
    elif choice == 3:
        print("Goodbye!")
    else:
        print("Invalid choice")
