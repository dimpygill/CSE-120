1. What Is a Loop?

A loop is a programming structure that repeats a block of code. Each time the loop repeats, we call it an iteration.

Suppose we want to print Hello five times. Without a loop, we could write:

print("Hello")
print("Hello")
print("Hello")
print("Hello")
print("Hello")

This works, but the instruction is repeated. A loop lets us express the same idea more clearly:

for i in range(5):
    print("Hello")
Hello Hello Hello Hello Hello
Key idea: A loop is useful whenever the program needs to perform the same type of action repeatedly.

2. Why Do We Use Loops?

Loops reduce repeated code and make programs easier to change. At this stage, we will use loops to repeat statements, count with numbers, repeat calculations, and keep asking for input until a condition is satisfied.

Example: If we want to print a message 30 times, we do not want to write 30 separate print() statements. One loop can repeat the statement for us.

Python has two main loop statements:

LoopUse it when...
forYou want to repeat something a controlled number of times, often by using range().
whileYou want repetition to continue as long as a condition remains True.

3. The for Loop

A for loop can repeat a block of code a controlled number of times. A very common way to use it is with range().

for number in range(5):
    # code that repeats

Here, number is one variable. Its value changes automatically on each iteration.

Example: Print numbers 0 through 4

for number in range(5):
    print(number)
0 1 2 3 4

Notice that range(5) starts at 0 and stops before 5.

number = 0→number = 1→number = 2→number = 3→number = 4

4. Understanding range()

range() gives a for loop a controlled set of integer values to use, one value per iteration.

range(stop)

for number in range(5):
    print(number)

This gives 0, 1, 2, 3, 4.

range(start, stop)

for number in range(1, 6):
    print(number)
1 2 3 4 5

The first value is included. The stop value is not included.

range(start, stop, step)

for number in range(2, 11, 2):
    print(number)
2 4 6 8 10

The third argument, 2, is the step: the amount added after each iteration.

Counting backward

for number in range(5, 0, -1):
    print(number)

print("Go!")
5 4 3 2 1 Go!

5. The while Loop

A while loop repeats while its condition is True. The condition is checked before every iteration.

while condition:
    # repeated code

Example: Count from 1 to 5

number = 1

while number <= 5:
    print(number)
    number = number + 1
1 2 3 4 5

The variable number begins at 1. After every iteration, number = number + 1 increases it. Eventually it becomes 6, so number <= 5 becomes False and the loop stops.

Important: A while loop usually needs something inside the loop that changes the condition. Otherwise, it may run forever.

Example: Keep asking until the user enters a positive number

number = int(input("Enter a positive number: "))

while number <= 0:
    print("That number is not positive.")
    number = int(input("Try again: "))

print("Thank you!")

This is a good use of while because we do not know in advance how many attempts the user will need.

6. Useful Loop Patterns: Counters and Running Totals

Counter

A counter is a variable used to count how many times something happens.

count = 0

for number in range(1, 6):
    count = count + 1

print("Iterations:", count)
Iterations: 5

Running total

A running total is a variable that keeps the total as the loop repeats. Each iteration adds a new value to the same variable.

total = 0

for number in range(1, 6):
    total = total + number

print("Total:", total)
Total: 15

Example: Add three numbers entered by the user

This example uses only ordinary variables. The variable number receives one input value during each iteration, and total keeps the running total.

total = 0

for i in range(3):
    number = int(input("Enter a number: "))
    total = total + number

print("Total:", total)
Trace it: If the user enters 10, 20, and 5, the value of total changes from 0 → 10 → 30 → 35.

7. Controlling a Loop with break and continue

break: stop the loop immediately

for number in range(1, 11):
    if number == 5:
        break
    print(number)
1 2 3 4

When number becomes 5, break ends the loop.

continue: skip the rest of the current iteration

for number in range(1, 6):
    if number == 3:
        continue
    print(number)
1 2 4 5

The loop itself continues, but the print() statement is skipped when number is 3.

8. More Examples

Example A: Print even numbers

for number in range(1, 11):
    if number % 2 == 0:
        print(number)
2 4 6 8 10

The % operator gives the remainder. An even number has a remainder of 0 when divided by 2.

Example B: Sum numbers entered by the user

total = 0

for i in range(3):
    number = int(input("Enter a number: "))
    total = total + number

print("Total:", total)

Example C: Multiplication table for one number

number = int(input("Enter a number: "))

for i in range(1, 11):
    answer = number * i
    print(number, "x", i, "=", answer)

This uses one user-entered number. The loop variable i changes from 1 through 10.

Example D: Password attempts

correct_password = "python123"
password = ""

while password != correct_password:
    password = input("Enter password: ")

print("Access granted")

9. Common Mistakes

Mistake 1: Forgetting indentation

Incorrect
for number in range(5):
print(number)
Correct
for number in range(5):
    print(number)

Mistake 2: Forgetting the colon

# Incorrect
for number in range(5)
    print(number)

# Correct
for number in range(5):
    print(number)

Mistake 3: Expecting the stop value from range()

for number in range(1, 5):
    print(number)

This prints 1 through 4, not 1 through 5. Use range(1, 6) if you need 1 through 5.

Mistake 4: Creating an infinite while loop

# Problem: number never changes
number = 1
while number <= 5:
    print(number)

A corrected version updates number:

number = 1
while number <= 5:
    print(number)
    number = number + 1

10. Choosing Between for and while

SituationGood choice
Print numbers 1–10for
Print a message a fixed number of timesfor
Repeat exactly 5 timesfor
Keep asking until input is validwhile
Continue until the user chooses Quitwhile
Rule of thumb: At this stage, use for with range() when you know or control how many times to repeat. Use while when repetition depends on a condition.
