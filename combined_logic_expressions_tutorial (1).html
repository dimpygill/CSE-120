Combining Logic Expressions: (A + B) · C

A step-by-step tutorial using a simple automatic room light.

1. The Scenario

A room light turns ON when motion is detected OR the wall switch is pressed, AND the main power is ON.

  • A: Motion detected (1 = Yes, 0 = No)
  • B: Wall switch pressed (1 = Yes, 0 = No)
  • C: Main power ON (1 = Yes, 0 = No)
  • Y: Light ON (1 = ON, 0 = OFF)
Y = (A + B) · C

+ means OR, and · means AND. The parentheses group the first two conditions together.

2. Solve the Expression in Two Steps

  1. Step 1 — OR: Evaluate A + B. The result is 1 if A or B (or both) is 1.
  2. Step 2 — AND: Combine that result with C. The final output is 1 only if the OR result is 1 and main power C is 1.

Example: A = 0, B = 1, C = 1.

(0 + 1) · 1 = 1 · 1 = 1 (Light ON).

Another example: A = 1, B = 0, C = 0.

(1 + 0) · 0 = 1 · 0 = 0 (Light OFF). Even though motion is detected, the main power is OFF.

3. Logic Gate Circuit

First, the OR gate combines A and B. Its output is connected to one input of the AND gate. C connects to the other AND input.

4. Complete Truth Table

ABCA + BY = (A + B) · C

There are 2³ = 8 input combinations because we have three inputs, each of which can be 0 or 1.

7. Key Takeaway

(A + B) · C means “A OR B, AND C.” An OR gate checks whether either trigger is active; an AND gate checks whether the trigger result and the power condition are both true.

Remember: The light cannot turn ON when C = 0, regardless of A or B.
