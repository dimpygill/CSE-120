🐍 Part 1 & 2

Installing Python

Python is a free, open-source programming language. Follow the steps below for your operating system.

1

Go to the Official Python Website

Open your browser and navigate to python.org.

⬇️ python.org/downloads
2

Download the Windows Installer

Click the yellow "Download Python 3.x.x" button. The site auto-detects Windows and offers the correct 64-bit installer.

💡
Tip: Always download from the official site to avoid malware.
3

Run the Installer

Open the downloaded .exe file. On the first screen:

  • ✅ Check "Add Python to PATH" — this is critical!
  • Click "Install Now" for the default setup (recommended).
⚠️
Important: If you skip "Add Python to PATH", commands like python won't work in the terminal.
4

Complete the Installation

Wait for the progress bar to finish. Click "Close" when you see "Setup was successful."

5

Verify Python is Installed

Open Command Prompt (press Win + R, type cmd, press Enter) and run:

C:\> python --version

You should see something like Python 3.12.x.

1

Go to the Official Python Website

Open Safari or any browser and go to python.org.

⬇️ python.org/downloads/macos
2

Download the macOS Installer

Click the big "Download Python 3.x.x" button. This downloads a .pkg file.

ℹ️
Note: macOS ships with an older Python 2 (or none at all on newer versions). Always install Python 3 from python.org.
3

Run the Package Installer

Double-click the downloaded .pkg file. Follow the installation wizard:

  1. Click Continue on the introduction screen.
  2. Agree to the License Agreement.
  3. Click Install and enter your Mac password if prompted.
4

Verify Python is Installed

Open Terminal (press Cmd + Space, search "Terminal") and run:

$ python3 --version

You should see Python 3.12.x (or whichever version you installed).

💡
Tip: On macOS, use python3 instead of python to ensure you're using Python 3.
⌨️ Part 3 & 4

Installing Visual Studio Code

VS Code is a free, lightweight code editor by Microsoft that works great with Python.

1

Download VS Code

Go to the official VS Code website and click "Download for Windows".

⬇️ code.visualstudio.com
2

Run the Installer

Open the downloaded VSCodeSetup-x64.exe. Accept the license agreement and click through the setup wizard. On the Additional Tasks page, check these recommended options:

  • ✅ Add "Open with Code" action to Windows Explorer
  • ✅ Add to PATH
  • ✅ Create a desktop icon (optional)
3

Launch VS Code

Click Finish to close the installer and launch VS Code. You can also find it in the Start Menu anytime.

4

Install the Python Extension

Inside VS Code, click the Extensions icon in the left sidebar (or press Ctrl + Shift + X). Search for Python and install the one by Microsoft.

💡
Why this matters: The Python extension adds syntax highlighting, IntelliSense, debugging, and the ability to run .py files directly in VS Code.
1

Download VS Code

Visit the official site and click "Download for Mac". This downloads a .zip file.

⬇️ code.visualstudio.com
2

Install VS Code

Double-click the downloaded .zip to extract it. Drag Visual Studio Code.app into your Applications folder.

ℹ️
Moving it to Applications ensures it's accessible from Spotlight and your Dock.
3

Launch VS Code

Open VS Code from Applications or via Spotlight (Cmd + Space → type "VS Code"). If macOS shows a security warning, click Open.

4

Add "code" Command to Terminal (Optional but Recommended)

Inside VS Code, open the Command Palette with Cmd + Shift + P. Type and select: "Shell Command: Install 'code' command in PATH". Now you can open any folder in VS Code by typing code . in Terminal.

5

Install the Python Extension

Click the Extensions icon in the left sidebar (or press Cmd + Shift + X). Search for Python and install the one by Microsoft.

🚀 Part 5

Run Your First Python Program

Now that both tools are installed, let's write and run a simple Python script in VS Code.

1

Create a New Folder

Create a folder on your Desktop called my_python_project. This will hold your Python files.

2

Open the Folder in VS Code

In VS Code, go to File → Open Folder and select your my_python_project folder.

3

Create a Python File

In the Explorer panel on the left, click the New File icon and name it hello.py.

4

Write Your Code

Type the following into hello.py:

print("Hello, World! 🎉")
print("Python is working!")
5

Run the File

Click the ▶ Run button (top-right) or right-click the file and select "Run Python File in Terminal". The integrated terminal will open and display:

Hello, World! 🎉
Python is working!
✅ Part 6

Verify Everything Works

Use these quick checks to confirm your setup is correct.

Open Command Prompt and run these commands:

C:\> python --version
Python 3.12.x

C:\> pip --version
pip 24.x from ...

C:\> code --version
1.9x.x
💡
All three commands should return version numbers, not errors. If code doesn't work, restart your PC after installation.

Open Terminal and run these commands:

$ python3 --version
Python 3.12.x

$ pip3 --version
pip 24.x from ...

$ code --version
1.9x.x
💡
If code isn't found, revisit Step 4 of the macOS VS Code section to install the shell command.

🎉 You're all set! Happy coding.
