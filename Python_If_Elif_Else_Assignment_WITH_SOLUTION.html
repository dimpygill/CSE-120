Part 1 — What is input()?

Until now, you may have placed values directly in your program:

name = "Alex"
score = 84

But sometimes we want the person running the program to enter the values. Python provides the input() function for this.

name = input("Enter student name: ")

When Python reaches this statement, it displays Enter student name: and pauses. The user types a value and presses Enter. That value is then stored in the variable name.

For example, if the user enters Alex:

print("Student:", name)

displays:

Student: Alex

Part 2 — Why Do We Convert the Data Type?

An important rule is that input() returns a string (str).

For example:

score = input("Enter final score: ")

If the user types 84, Python initially receives it as the text "84", not the integer 84.

For this assignment, we need to compare the score with numbers such as 90, 80, and 70. Therefore, we convert it to an integer:

score = int(input("Enter final score: "))

The process is:

User types 84
      ↓
input() receives "84"
      ↓
int("84")
      ↓
84

Now score is an integer and can be used in numeric comparisons such as:

score >= 90

We do not convert the student’s name because a name is text.

Information Example Data Type Needed Code
Student name Alex str input()
Final score 84 int int(input())

For this assignment, assume the final score is entered as a whole number from 0 to 100.

Part 3 — if, elif, and else

A conditional allows a program to make a decision.

if condition:
    # runs if this condition is True

elif another_condition:
    # runs if the previous condition was False
    # and this condition is True

else:
    # runs if none of the conditions above were True

Example:

if score >= 90:
    print("Grade A")
elif score >= 80:
    print("Grade B")
else:
    print("Grade below B")

Python checks the conditions from top to bottom. Once it finds a condition that is True, it executes that section and skips the remaining elif/else sections.

Notice the indentation. Statements belonging to an if, elif, or else must be indented.

Basic Assignment Solution

# Student Grade Advisor - Solution

# Ask the user for the student's information
name = input("Enter student name: ")
score = int(input("Enter final score: "))

# Determine the student's grade
if score >= 90:
    grade = "A"
    message = "Excellent work!"

elif score >= 80:
    grade = "B"
    message = "Good job!"

elif score >= 70:
    grade = "C"
    message = "Satisfactory work."

elif score >= 60:
    grade = "D"
    message = "You passed, but improvement is needed."

else:
    grade = "F"
    message = "Please see your instructor for additional support."

# Display the result
print("\n--- Student Result ---")
print("Student:", name)
print("Final Score:", score)
print("Grade:", grade)
print("Message:", message)

Example Run

Enter student name: Alex
Enter final score: 84

Final Score: 84
Grade: B
Message: Good job!

Why Do These Conditions Work?

Python checks the conditions from top to bottom. For example, if the score is 84:

score >= 90   → False
score >= 80   → True

As soon as Python finds the first True condition, it executes that block and skips the remaining elif and else blocks. Therefore, a score of 84 receives a B.

Optional Challenge Solution — Invalid Score

The invalid-score condition comes first so that the program checks whether the entered score is valid before assigning a letter grade.

name = input("Enter student name: ")
score = int(input("Enter final score: "))

if score < 0 or score > 100:
    print("Invalid score. Please enter a score between 0 and 100.")

elif score >= 90:
    grade = "A"
    message = "Excellent work!"

elif score >= 80:
    grade = "B"
    message = "Good job!"

elif score >= 70:
    grade = "C"
    message = "Satisfactory work."

elif score >= 60:
    grade = "D"
    message = "You passed, but improvement is needed."

else:
    grade = "F"
    message = "Please see your instructor for additional support."

if score >= 0 and score <= 100:
    print("\n--- Student Result ---")
    print("Student:", name)
    print("Final Score:", score)
    print("Grade:", grade)
    print("Message:", message)

What Is New in the Challenge?

The expression score < 0 or score > 100 checks whether the score falls outside the valid range. The keyword or means that either condition being true is enough to identify the score as invalid.

The final if checks that the score is between 0 and 100 before displaying the grade information.
