Digital Logic Gates: Scenario Questions and Complete Solutions

Three worked examples with the original scenario questions, input/output definitions, complete truth tables, Boolean expressions, circuit diagrams, and reasoning.

General Instructions

  • Read each scenario carefully.
  • Identify the inputs (conditions) and desired output.
  • Draw a truth table, write a logic expression, and show your reasoning clearly.

Notation: 0 = FALSE/OFF, 1 = TRUE/ON; · = AND, + = OR, and ¬ = NOT. Each three-input truth table has 2³ = 8 rows.

Question 1 — Car Safety System

Scenario: A car will start only if the seatbelt is fastened (A), the brake is pressed (B), and the driver is NOT drunk (C = 1 means drunk).

Solution 3: Boolean expression

Y = A · B · ¬C

The car starts only if A = 1, B = 1, and C = 0. NOT converts C = 0 into ¬C = 1, and the AND gate requires all three values to be 1.

Solution 5: Reasoning example

For A = 1, B = 1, C = 0: ¬C = 1, so Y = 1 · 1 · 1 = 1. The car starts. Any missing requirement produces Y = 0.

Question 2 — Fire Alarm System

Scenario: A fire alarm should sound if smoke is detected (A) OR the temperature is too high (B). However, if the system is in maintenance mode (C = ON), the alarm should NOT sound.
Tasks / Questions
  1. Identify inputs A, B, C and the output.
  2. Write the condition in words.
  3. Create the complete truth table.
  4. Write the Boolean logic expression.
  5. Draw the logic gate circuit and explain its operation.

Solution 1: Inputs and output

Solution 2: Condition in words

The alarm sounds if smoke is detected OR temperature is too high (or both), AND maintenance mode is OFF.

Solution 4: Boolean expression

Y = (A + B) · ¬C

First combine smoke and temperature with OR. Invert maintenance mode with NOT. Finally combine those results with AND, so maintenance mode suppresses the output.

Solution 5: Circuit diagram

Solution 6: Reasoning example

If smoke = 1, high temperature = 0, and maintenance = 0, then Y = (1 + 0) · 1 = 1: the alarm sounds. If maintenance = 1, then ¬C = 0 and Y = 0 regardless of A and B.

Design note: This maintenance override is part of the simplified classroom scenario. Real fire alarm systems require additional safety and regulatory safeguards.

Question 3 — Smart Home Door Alert

Scenario: A smart door alert should ring if the door is opened (A) AND it is nighttime (B). BUT if the system is turned OFF (C), then the alert should NOT ring.

The alert requires an open door AND nighttime AND a system that is not OFF. Invert C and apply AND to all three conditions.

Solution 5: Reasoning example

For A = 1 (door open), B = 1 (nighttime), C = 0 (system ON), ¬C = 1. Thus Y = 1 · 1 · 1 = 1: the alert rings. If the system is OFF, Y = 0.
