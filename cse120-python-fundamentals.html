Part 1
Storing Information

Variables

A variable is a named container that holds a value in your program's memory. Think of it like a labelled box — you put something in, you can look it up by name later, and you can swap the contents whenever you like.

📦 Analogy — The Labelled Box

Imagine a shelf of boxes, each with a label on the front. You write temperature = 98.6 and Python creates a box labelled temperature and puts the value 98.6 inside it. Any time you need that value, just say the label and Python goes and fetches it.

Creating a Variable

In Python, you create a variable with the assignment operator — a single equals sign =. The variable name goes on the left, the value on the right.

python
# Creating variables student_name = "Maria" age = 20 gpa = 3.75 is_enrolled = True # Using variables print(student_name) # Maria print(age) # 20 print(gpa) # 3.75 print(is_enrolled) # True

⚠️ Naming Convention — Use snake_case

Python programmers use snake_case — all lowercase letters with underscores between words. This is not enforced by Python but it's the professional standard: total_cost not TotalCost or totalcost.

= Means Assign, Not Equal

In math, = means "these two sides are equal." In Python, = means "store this value in this variable". This is called assignment.

python
# This is legal Python — impossible in math! count = 5 print(count) # 5 count = count + 1 # "take count (5), add 1, store the result back in count" print(count) # 6 count = count * 2 print(count) # 12

Multiple Assignment

Python lets you assign multiple variables on a single line:

python
# Assign the same value to several variables x = y = z = 0 print(x, y, z) # 0 0 0 # Assign different values in one line (tuple unpacking) length, width, height = 5, 3, 2 print(length, width, height) # 5 3 2 # Swap two variables (unique Python trick!) a, b = 10, 20 a, b = b, a print(a, b) # 20 10

Updating Variables — Shorthand Operators

Writing count = count + 1 is so common that Python has a shorthand for it:

python
score = 100 score += 10 # same as: score = score + 10 → 110 score -= 5 # same as: score = score - 5 → 105 score *= 2 # same as: score = score * 2 → 210 score //= 3 # same as: score = score // 3 → 70 print(score) # 70

int — Whole Numbers

Integers are whole numbers — no decimal point. They can be positive, negative, or zero. Python integers can be arbitrarily large.

python
students = 30 temperature = -5 year = 2026 zero = 0 print(type(students)) # <class 'int'> print(students + 5) # 35 — math works as expected print(year * 2) # 4052

float — Decimal Numbers

Floats are numbers with a decimal point. Use them whenever precision matters — measurements, prices, averages.

python
pi = 3.14159 voltage = 5.0 # still float even though it looks whole temperature = -2.5 price = 19.99 print(type(pi)) # <class 'float'> print(10 / 3) # 3.3333333333333335 — / always gives float print(10 // 3) # 3 — // gives int (floor division)

str — Text (Strings)

A string is any sequence of characters wrapped in quotes. You can use single or double quotes — both work.

python
name = "Alice" city = 'Vancouver' message = "She said: 'Hello!'" # mix quotes when needed # String operations print(name + " " + city) # Alice Vancouver (concatenation) print(name * 3) # AliceAliceAlice (repetition) print(len(name)) # 5 (number of characters) print(name.upper()) # ALICE print(name.lower()) # alice # f-strings — the modern way to embed variables in text age = 20 print(f"My name is {name} and I am {age} years old.") # My name is Alice and I am 20 years old.

bool — True or False

A boolean has exactly two possible values: True or False. Notice the capital first letter — that matters in Python.

python
is_raining = True is_finished = False has_passed = 85 > 60 # evaluates to True is_equal = 10 == 5 # evaluates to False print(type(is_raining)) # <class 'bool'> print(has_passed) # True print(is_equal) # False

Checking the Type — type()

python
print(type(42)) # <class 'int'> print(type(3.14)) # <class 'float'> print(type("hello")) # <class 'str'> print(type(True)) # <class 'bool'>

Type Conversion

You can convert between types using built-in functions:

python
# str → int / float (common after input()) user_input = "42" number = int(user_input) # "42" → 42 decimal = float(user_input) # "42" → 42.0 # int / float → str age = 20 label = "Age: " + str(age) # "Age: 20" # float → int (truncates — drops the decimal) print(int(3.9)) # 3 ← NOT rounded, just truncated! print(int(3.1)) # 3 # bool conversions print(int(True)) # 1 print(int(False)) # 0
🚫 Common Misconception — "25" vs 25

"25" is a string — two characters, the digit 2 and the digit 5. Python cannot do math with it directly. 25 is an integer. They look alike but behave completely differently:

print("25" + "10") # "2510" — string join! print(25 + 10) # 35 — math!

Always convert with int() or float() after input().

📐 Understanding Modulo (%)

Modulo gives you the remainder after division. Think of it like dividing items into groups: 17 % 5 asks "if I put 17 items into groups of 5, how many are left over?" 3 full groups of 5 = 15, leftover = 2. So 17 % 5 = 2.

Common uses: checking even/odd (n % 2), wrapping around a range, dividing time into hours/minutes.

📦 What does "floor" mean?

The floor of a number is the largest whole number that is less than or equal to it — in other words, always round toward negative infinity (always round down, never up).

floor(3.9) = 3    floor(3.1) = 3    floor(-3.1) = -4 (not -3!)

⚠️ = vs == — The Most Common Beginner Mistake

= assigns a value: x = 5 stores 5 in x.
== compares two values: x == 5 asks "is x equal to 5?"
Using = instead of == in a condition is a syntax error in Python 3.

x = 5 # ← assignment: store 5 in x print(x == 5) # ← comparison: True print(x == 6) # ← comparison: False

Part 4
Making Decisions

if Statements

So far your programs run every line top to bottom. An if statement lets Python choose which code to run based on a condition. It is the foundation of all decision-making in programming.

🚦 Analogy — A Traffic Light

A traffic light asks: "Is the light red?" If yes, stop. If it is amber, slow down. Otherwise, go. Your Python program can make the same kind of branching decisions with if / elif / else.

Simple if

The simplest form: run a block of code only when the condition is True. If it's False, skip the block entirely.

python — simple if
temperature = 38 if temperature > 37.5: print("You have a fever.") print("Please rest and drink water.") # This line always runs — it's outside the if block print("Temperature check complete.")

The indented block (4 spaces or 1 tab) is the if body. Python uses indentation — not braces — to group code. Everything indented under the if only runs when the condition is True.

if / else

Add an else to handle the False case — one of the two blocks always runs.

python — if / else
score = 72 if score >= 60: print("Pass! Well done.") else: print("Did not pass. Please see your instructor.") # With score = 72 → output: "Pass! Well done." # With score = 45 → output: "Did not pass. Please see your instructor."

if / elif / else — Multiple Conditions

When you have more than two cases, use elif (short for "else if"). Python checks conditions top to bottom and runs the first one that is True, then skips the rest.

python — if / elif / else
score = 85 if score >= 93: grade = "A" elif score >= 83: grade = "B" elif score >= 73: grade = "C" elif score >= 60: grade = "D" else: grade = "F" print(f"Score {score} → Grade {grade}") # Score 85 → Grade B
🤔 Predict — What grade does score = 73 get?
▶ Show Answer

Score 73 → Grade C.

Python checks in order: 73 >= 93? No. 73 >= 83? No. 73 >= 73? Yes → grade = "C". The remaining elif and else are skipped.

Nested if Statements

You can put an if inside another if. The inner if only runs when the outer condition is True. Indent one extra level.

python — nested if
age = 20 has_ticket = True if age >= 18: print("Age check passed.") if has_ticket: print("Welcome! Enjoy the show.") else: print("Please buy a ticket first.") else: print("Sorry — must be 18 or older.")

if with Logical Operators

Combine conditions with and, or, not to avoid deep nesting:

python — combined conditions
# Same logic as nested, but flat if age >= 18 and has_ticket: print("Welcome!") elif age < 18: print("Must be 18 or older.") else: print("Need a ticket.") # Check a range bmi = 22.4 if 18.5 <= bmi < 25.0: print("Healthy BMI range") # not operator is_weekend = False if not is_weekend: print("It's a weekday — class is on!")

name = input("Student name: ") score = int(input("Score (0-100): ")) if score < 0 or score > 100: print("Invalid score entered.") elif score >= 93: print(f"{name}: A — Outstanding!") elif score >= 83: print(f"{name}: B — Great work.") elif score >= 73: print(f"{name}: C — Satisfactory.") elif score >= 60: print(f"{name}: D — Needs improvement.") else: print(f"{name}: F — Please see your instructor.")

Example C — Even / Odd / Divisibility

python
n = int(input("Enter a number: ")) if n % 2 == 0: print(f"{n} is even.") else: print(f"{n} is odd.") # More specific: divisible by 3 and 5? if n % 15 == 0: print("Divisible by both 3 and 5 (FizzBuzz!)") elif n % 3 == 0: print("Divisible by 3 (Fizz)") elif n % 5 == 0: print("Divisible by 5 (Buzz)")
🚫 Indentation Errors — The Beginner Trap

Python uses indentation to define code blocks. Inconsistent indentation causes an IndentationError and your program won't run at all.

# ❌ WRONG — inconsistent indent if x > 0: print("positive") # IndentationError! # ✅ CORRECT — 4 spaces inside the block if x > 0: print("positive")
