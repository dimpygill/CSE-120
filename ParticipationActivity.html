Python Decision Making

In-Class Programming Assignment

Individual Activity

Assignment Overview

Complete this activity independently during class. The goal is to practice using Python to make decisions based on multiple conditions.

Grading: This is a participation-based assignment. You will receive full points for submitting your completed attempt.

Programming Problem

Write one Python program for a college course registration system. The program will collect information about a student and determine whether the student is eligible for the Advanced Course, the Regular Course, or is not currently eligible to register.

Your goal: Use if, elif, else, comparison operators, and logical operators to make the registration decision.

Step 1 — Ask the User for Information

Your program must use input() to ask the user for:

  • Their age
  • Their GPA
  • Whether they have completed the prerequisite course (yes or no)

Step 2 — Make the Registration Decision

After receiving the information, your program must apply the following rules in this order:

1 Advanced Course

If the student's GPA is 3.0 or higher AND the prerequisite course has been completed, display:

You are eligible for the Advanced Course.

2 Regular Course

Otherwise, if the student's GPA is 2.0 or higher AND the student is 18 or older, display:

You are eligible for the Regular Course.

3 Not Eligible

If neither of the conditions above is satisfied, display:

You are not currently eligible to register.

Step 3 — Python Requirements

Your complete program must use all of the following:

input()
Get information from the user
if
Check the first condition
elif
Check the second condition
else
Handle the default case
and
Combine conditions
>=   ==
Compare values
print()
Display the final decision
Important: Your program should ask the user for the values. Do not hard-code the age, GPA, or prerequisite answer from the examples shown below.

Expected Results

After you have written the complete program described above, test it with different values. The following scenarios show the expected behavior for each possible decision.

Before You Submit

Run your program several times using different values.

Make sure you test values that cause Python to execute:

  • the if branch
  • the elif branch
  • the else branch
Do not test your program only once. Different input values should produce different results.
