Part 1
Foundation

What Is Programming?

Computers only do what they are told — exactly

A computer is incredibly fast and precise, but on its own it does nothing. It needs instructions. A computer program is simply a list of instructions that tells a computer what to do, step by step.

Think of a recipe. A recipe tells a cook: first do this, then do that, if this happens do this instead. A computer program works the same way — except the "cook" is the computer and the instructions have to be written in a language the computer can understand.

What is a programming language?

Computers don't understand English (or any human language). They understand patterns of electrical signals that represent 1s and 0s. Writing instructions directly in 1s and 0s is possible, but exhausting and error-prone.

A programming language is a middle ground — a formal language that humans can learn to write, which can then be translated into something the computer can execute. Python, Java, C++, and JavaScript are all programming languages.

Analogy If you speak English and your friend speaks only Mandarin, you might use a translator. A programming language is like that translator — you write instructions in a readable form, and the computer converts them into actions it can perform.

What is Python?

Python is a programming language created in 1991 and designed to be as readable as possible. Python code looks a lot like plain English, which is one reason it is one of the most popular first languages to learn.

Engineers, scientists, data analysts, AI researchers, and web developers all use Python regularly. It is also free, runs on Windows, Mac, and Linux, and has a huge community of users who have built thousands of helpful tools you can use.

What is source code?

When you write instructions in Python, what you type is called source code (or just "code"). It's the human-readable version of the program — before the computer runs it.

What does it mean to "run" a program?

When you run a program, you are telling the computer to read your source code and execute it — to actually carry out the instructions. The result is whatever the program is designed to do: print text, calculate a value, ask a question, and so on.

The Python interpreter

Python uses something called an interpreter. The interpreter reads your code one line at a time, from top to bottom, and executes each line before moving on to the next. This is different from languages like C++ that compile all the code first before running any of it.

Think of the interpreter as someone reading your recipe out loud and cooking each step as they read it, rather than reading the whole recipe before starting.

Your first program

By tradition, the very first program anyone writes in any language is "Hello, world!" Here it is in Python:

python
print("Hello, world!")

Let's break down every single part of this line:

  • print — this is a built-in function (a tool Python gives you for free). Its job is to display something on the screen. Don't worry too much about the term "function" — for now, just know that print means "show this".
  • ( ) — the parentheses tell Python where the function's instructions begin and end. Whatever is inside the parentheses is what you want to display.
  • "Hello, world!" — the quotation marks tell Python this is a piece of text (called a string). Everything between the quotes is treated as literal text, not a command.

Problem Solving

From a Problem to a Program

Programming is problem solving first

Here's something many beginners don't realize: most of programming has nothing to do with typing code. The hard part — the part that takes real skill — is figuring out what steps to take to solve the problem. The code comes after.

Before you write a single line of Python, it pays to think through:

  • What is the problem I'm trying to solve?
  • What information do I start with? (Inputs)
  • What do I need to produce? (Outputs)
  • What steps transform the inputs into the outputs? (Process)

What is an algorithm?

An algorithm is just a step-by-step plan for solving a problem. You already use algorithms every day without calling them that. A recipe is an algorithm. Directions to a destination are an algorithm. Your morning routine is an algorithm.

In programming, we write algorithms in plain English first — then translate them into code.

The beginner workflow Problem → Inputs → Process → Outputs → Algorithm (plain English) → Code → Test → Debug

Part 3
Storing Values

Variables

What is a variable?

Imagine a labeled box. You can put a value inside the box, take it out later, or swap it for a different value. In programming, a variable is exactly that — a named location in the computer's memory where you can store a value.

Why do we need variables? Because programs need to remember things. A program that calculates your electricity bill needs to remember the meter reading. A program that runs a traffic light needs to remember how many seconds have passed.

temperature ↓ ┌─────────────┐ │ 72 │ └─────────────┘

The box is labeled temperature. Inside it is the value 72.

Creating a variable in Python

python
temperature = 72

This line does one thing: it creates a box labeled temperature and stores the value 72 in it.

  • temperature — the variable name (the label on the box)
  • = — the assignment operator. This does NOT mean "equals" in the mathematical sense. It means "take the value on the right and store it in the variable on the left."
  • 72 — the value being stored
⚠️ Common Misconception — What does = mean?

In math class, x = 5 means "x and 5 are equal." In Python, x = 5 means "store the value 5 in a variable called x." They look the same but mean very different things.

A math equation x = x + 1 makes no sense mathematically. But in Python it means: "take whatever is in x right now, add 1 to it, and store the result back in x." This is completely valid Python.

Variable naming rules

  • Variable names can contain letters, numbers, and underscores
  • They cannot start with a number: 1sensor is invalid, sensor1 is fine
  • They cannot contain spaces: use underscores instead — room_temperature
  • They are case-sensitive: Voltage and voltage are two different variables
  • Choose descriptive names: speed is better than s, battery_level is better than bl

Input and Output

Output: print()

You've already used print(). It displays a value on the screen. Here are a few things to know:

python

Input: input()

So far our programs have had fixed values. But most useful programs ask the user for information. Python does this with input().

python
name = input("What is your name? ") print("Hello,", name)

When Python reaches input(), it pauses and waits for the user to type something and press Enter. Whatever the user typed is stored in the variable name.

The text inside the quotes — "What is your name? " — is the prompt: the message shown to the user asking them what to type.

▶ Check Your Answer

⚠️ Critical: input() always gives you text

Here is one of the most common mistakes beginners make. Look at this code:

python
age = input("Enter your age: ") next_age = age + 1 print(next_age)
🤔 What do you think will happen?

If the user types 20, will this print 21?

▶ Check Your Answer

No — it will crash with an error:

TypeError: can only concatenate str (not "int") to str

Why? input() always returns a string, even if the user typed a number. So age contains the text "20", not the number 20. When Python tries to do "20" + 1, it sees a string + a number and doesn't know what to do.

Converting input to a number

To fix this, we convert the string to a number using int() or float():

python
age = int(input("Enter your age: ")) # convert to integer next_age = age + 1 print("Next year you will be:", next_age)

Now int() converts the text "20" into the number 20 before storing it in age. The math works.

Use float() when the user might enter a decimal number:

python
voltage = float(input("Enter voltage: ")) # works for 3.3, 5.0, etc.

Part 7
Making Choices

Decisions with if

Why do programs need decisions?

So far, our programs run every line from top to bottom without any choices. But most real programs need to respond differently depending on the situation:

  • If the temperature is above 100°F, trigger a warning.
  • If the battery is below 20%, display "Low battery."
  • If the user enters the correct password, let them in.

In Python, we use the if statement to make decisions.

Comparison operators

To make a decision, we need to compare values. Python uses these comparison operators:

OperatorMeaningExample
==Equal tox == 5
!=Not equal tox != 5
>Greater thanx > 5
<Less thanx < 5
>=Greater than or equal tox >= 5
<=Less than or equal tox <= 5
⚠️ = versus == — The most common beginner mistake

= means assignment — store a value in a variable.

== means comparison — ask "are these two things equal?"

x = 5 # stores 5 in x (assignment) x == 5 # asks "is x equal to 5?" (comparison — True)

Using = inside an if condition is a very common error that produces confusing results.

The if statement

python
temperature = 85 if temperature > 80: print("Warning: temperature is high!")

Notice the structure:

  • if — the keyword that starts a decision
  • temperature > 80 — the condition (a question that's either True or False)
  • : — the colon is required at the end of the if line
  • The indented line — Python only runs this if the condition is True. The 4 spaces of indentation are required.
temperature > 80? / \ Yes No | | Print warning (do nothing)

if / else

python
temperature = 72 if temperature > 80: print("Warning: temperature is high!") else: print("Temperature is normal.")
🤔 Predict — What does this display?

The temperature is 72. Will the program print the warning or "Temperature is normal."?

▶ Check Your Answer

Temperature is normal.

72 is NOT greater than 80, so the condition is False. Python skips the if block and runs the else block instead.

if / elif / else — Multiple options

python
battery = 15 if battery > 80: print("Battery is full.") elif battery > 20: print("Battery is OK.") else: print("Low battery — charge now!")

elif is short for "else if." Python checks each condition in order and runs the first one that is True. If none are True, it runs else.

Repetition and Loops

The problem: doing something many times

What if you needed to print "Checking sensor..." 100 times? You could write 100 print statements, but that's absurd. And what if it needed to be 1,000 times? Or the number came from user input?

Programs need a way to repeat instructions. That's exactly what a loop does.

The for loop

The for loop tells Python: "Do this a set number of times."

python
for i in range(5): print(i)

Let's break down every part:

  • for — the keyword that starts the loop
  • i — the loop variable. Python automatically changes this value each time through the loop. You can name it anything, but i is a common choice.
  • in — connects the variable to the sequence of values
  • range(5) — generates the numbers 0, 1, 2, 3, 4. It gives you 5 values starting from zero.
  • : — the required colon at the end of the for line
  • The indented line — this runs once for each value in range(5)
🤔 Predict — What does this print?
for i in range(5): print(i)
▶ Check Your Answer

It prints:

0 1 2 3 4

range(5) gives 0, 1, 2, 3, 4 — five numbers starting from 0, not 1 through 5. This surprises many beginners.

⚠️ Common Misconception — range(5) is NOT 1 to 5

range(5) produces: 0, 1, 2, 3, 4 — it starts at 0 and gives you 5 values.

If you want 1 through 5, use range(1, 6).

for i in range(1, 6): # 1, 2, 3, 4, 5 print(i)

The simplest for loop just counts through a sequence of numbers. Here we print a greeting 5 times:

Example 4 — Collecting sensor readings and averaging them

Now let's apply the accumulation pattern to a real engineering scenario — collecting temperature readings and finding the average:

total = 0 # running total starts at zero for i in range(5): reading = float(input("Enter temperature reading: ")) total = total + reading # add this reading to the total average = total / 5 print("Average temperature:", average)

The loop asks for a reading 5 times. Each reading gets added to total. After the loop finishes, we divide the total by 5 to get the average. The average calculation happens outside the loop — we only need it once, after all readings are collected.

Example 5 — Loop with an if inside

Loops and if statements work very well together. Here we check each temperature reading as it comes in:

python
for i in range(3): temperature = float(input("Enter temperature: ")) if temperature > 100: print("⚠ Danger: Overheating!") else: print("✓ Safe.")

The indentation is important here. The if statement and the else statement are both indented inside the for loop — so they run once for every reading. After 3 readings, the loop stops.

The while loop

The for loop is perfect when you know exactly how many times to repeat. But sometimes you don't know in advance — you want to keep going until something changes. That's when you use a while loop.

A while loop keeps running as long as a condition is True. The moment the condition becomes False, the loop stops.

while Example 1 — Counting with a while loop

Let's look at the simplest while loop — counting from 1 to 5:

python
count = 1 # start at 1 while count <= 5: print("Count is:", count) count = count + 1 # MUST increase count or loop never stops print("Done!")

Here is how Python reads this:

  1. Is count (1) ≤ 5? Yes → run the indented code, count becomes 2
  2. Is count (2) ≤ 5? Yes → run the indented code, count becomes 3
  3. Is count (3) ≤ 5? Yes → run the indented code, count becomes 4
  4. Is count (4) ≤ 5? Yes → run the indented code, count becomes 5
  5. Is count (5) ≤ 5? Yes → run the indented code, count becomes 6
  6. Is count (6) ≤ 5? No → loop ends, print "Done!"

while Example 2 — Countdown

A while loop can also count downward. We just subtract instead of add:

python
countdown = 5 while countdown > 0: print(countdown) countdown = countdown - 1 # subtract 1 each time print("Blast off! 🚀")
🤔 Predict — What is the full output?

The loop starts at 5 and subtracts 1 each time. When countdown reaches 0, the condition countdown > 0 is False, the loop stops, and "Blast off!" prints.

while Example 3 — Repeat until the user enters a valid answer

This is one of the most useful patterns: keep asking the user for input until they give a valid answer. A for loop can't do this easily, because we don't know in advance how many tries the user will need.

python
password = "" # start with empty string while password != "open123": password = input("Enter password: ") print("Access granted!")

The loop keeps asking for the password as long as it doesn't match "open123". The moment the user types the correct password, the condition password != "open123" becomes False, and the loop stops.

✅ Check Your Understanding

In the password example above — what happens if the user types the correct password on the very first try? Does the loop run at all?

▶ Check Your Answer

Yes, the loop runs once. Python checks the condition before each iteration. The first time, password is an empty string "", so the condition password != "open123" is True. The loop runs, the user types the correct password, then Python checks the condition again — now it's False — and the loop stops.

So even with a correct first answer, the loop body executes exactly once.

⚠️ Infinite loops — what goes wrong

A while loop must eventually make its condition False — otherwise it runs forever. This is called an infinite loop and it's one of the most common beginner mistakes.

🐛 What goes wrong here?
count = 1 while count <= 5: print("Count is:", count) # count = count + 1 is missing!

What happens? How do you fix it?

▶ Check Your Answer

Infinite loop. count starts at 1 and never changes. The condition count <= 5 is always True. Python prints "Count is: 1" forever until you force-quit the program (press Ctrl+C).

Rule: always make sure something inside the loop changes the variable that the condition checks. Without that, the condition can never become False.

Fix:

count = 1 while count <= 5: print("Count is:", count) count = count + 1 # this line makes the condition eventually False

Part 9
Finding and Fixing Errors

Debugging

Errors are normal

Every programmer — beginner and expert — writes buggy code. Errors are not a sign of failure; they are a normal part of the process. The skill you need to develop is not "write perfect code," it's "find and fix problems quickly."

This skill is called debugging.

Three types of errors

1. Syntax Errors — "Python can't read this"

Python cannot understand the code because it violates the rules of the language. Like a grammatical error in English — if you write a sentence that is completely garbled, the reader gives up.

print("Hello" # SyntaxError: missing closing parenthesis

2. Runtime Errors — "Something went wrong while running"

The code looks correct, but something goes wrong while it is running. Python crashes and shows an error message.

x = int("hello") # ValueError: can't convert "hello" to an integer

3. Logic Errors — "The program runs but gives the wrong answer"

The most sneaky type. Python runs the code without crashing, but the result is wrong because the logic is flawed.

# Trying to calculate the average of 3 numbers total = 10 + 20 + 30 average = total / 2 # Bug: should divide by 3, not 2 print(average) # prints 30.0 instead of correct 20.0

The debugging strategy

Read → Predict → Run → Read the error message → Locate → Fix → Test again
Never just randomly change things hoping the error goes away. Read the error message carefully — Python usually tells you exactly which line has a problem.

▶ Check Your Answer

Indentation Error. The print(i) line needs to be indented (4 spaces) to be inside the for loop. Without indentation, Python doesn't know this line belongs to the loop.

temperature = 98.6 print(temperture)
▶ Check Your Answer

🐛 Bug 5 — Using = instead of ==

Syntax Error. Inside an if condition, you compare with ==, not assign with =.

This prints 0 1 2 3 4 — but the goal was 1 through 5. Fix it.

▶ Check Your Answer

Logic Error. range(5) gives 0 to 4. To get 1 to 5, use range(1, 6).

for i in range(1, 6): print(i)
🐛 Bug 8 — Wrong calculation
# Convert Celsius to Fahrenheit: F = (C * 9/5) + 32 celsius = 100 fahrenheit = celsius * 9 / 5 + 32 print(fahrenheit) # should print 212

Run it mentally — does it print the right answer? If not, what went wrong?

🏆 Temperature Monitor — Build It Yourself

The problem: Build a temperature monitoring program. It asks the user for 5 temperature readings, checks if each is safe (<= 100°F) or dangerous (> 100°F), calculates the average, and reports the result.

Work through this stage by stage

Stage 1 — Understand

What are the inputs? What is the process? What should the output look like? Write this in plain English before touching code.

Stage 2 — Decompose

Break the problem into smaller parts: (a) collecting readings, (b) checking each reading, (c) calculating the average, (d) displaying the final report.

Stage 3 — Write the loop and safety check

Use a for loop to ask for 5 readings. Inside the loop, use an if/else to print "Safe" or "Danger: Overheating!" for each reading. Also accumulate a running total.

Stage 4 — Calculate and display the average

After the loop finishes, calculate the average (total ÷ 5) and print a final summary report.

💡 Hint — Stuck on Stage 3?

Start with just the loop and if/else — ignore the total for now:

for i in range(5): temp = float(input("Enter reading: ")) if temp > 100: print("Danger: Overheating!") else: print("Safe.")

Once that works, add total = 0 before the loop and total = total + temp inside the loop.

▶ Full Solution — Try it yourself first!
python — fully commented solution
# Set up before the loop total = 0 # accumulator — starts at zero readings = 5 # how many readings to collect print("--- Temperature Monitor ---") # Loop 5 times for i in range(readings): temp = float(input("Enter reading: ")) # Check this reading immediately if temp > 100: print(" → Danger: Overheating!") else: print(" → Safe.") # Add to running total total = total + temp # After ALL 5 readings: calculate and display average average = total / readings print("--------------------------") print("Average temperature:", average, "°F")

Why it works:

  • total = 0 is set BEFORE the loop — this is the accumulator starting point.
  • Inside the loop, three things happen every iteration: get input, check it with if/else, add to total.
  • The if/else runs independently each time — it doesn't affect the next iteration or the total.
  • The average is calculated AFTER the loop — only once, using the final total.
